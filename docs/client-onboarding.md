# Client Onboarding Playbook

## 1. Discovery
- Confirm business objectives and KPI definitions.
- Identify audience, decision cadence and required drilldowns.
- Document data owners and refresh expectations.

## 2. Data readiness
- Validate schema, grain, keys and date coverage.
- Check missing values, duplicates and reconciliation totals.
- Confirm source-to-report lineage.

## 3. Semantic model
- Prefer a star schema.
- Keep dimensions conformed.
- Centralize KPI logic in measures.

## 4. UAT
- Validate KPI totals against approved source reports.
- Test filters, drill-through, row-level security and edge cases.
- Capture sign-off and known limitations.

## 5. Handover
- Provide data dictionary, refresh instructions, ownership matrix and issue process.
- Never commit credentials, tokens, client exports or confidential screenshots.
